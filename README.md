# RecipeSense 🍳

## AI Recipe Understanding & Ingredient Substitution System

RecipeSense is an AI-powered web application that understands recipe text, extracts important recipe information, suggests ingredient substitutions, and helps users discover recipes they can prepare using the ingredients they already have.

The system combines Natural Language Processing (NLP), recipe matching, and a real-world recipe dataset to provide practical cooking assistance.

---

## 🚀 Features

### 1. Recipe Analysis

Users can enter a recipe containing ingredients and cooking instructions.

RecipeSense extracts:

- Ingredient names
- Quantities
- Units
- Normalized ingredient names
- Cooking actions

Example:

```text
2 cups rice
1 onion, chopped
2 cloves garlic
1 tablespoon butter

Heat the butter.
Add the onion and garlic.
Cook until soft.
